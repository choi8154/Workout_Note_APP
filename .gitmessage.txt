# 이 줄 밑에 작성 ㄱㄱ

# 무었을 왜 변경했는지 밑에 작성하삼


# 형식: type(scope): summary
# 예시: Feat(auth): 로그인 엔드포인트 추가.

# Feat: 기능
# Fix: 버그 수정
# Refactor: 리팩터링. ex) 함수 분리, 변수명/클래스명 정리, 중복 코드 제거, 파일구조 재배치
# Test: 테스트코드 수정
# Docs: 주석 및 문서 작업
# Chore: 오타와 같은 기술적이지 않은 오류 및 사소한 수정
# Ci: Ci로 인한 코드 최적화와 관련된 수정
# Perf: 성능 수정. ex) 쿼리 횟수 줄임, 캐시 추가, 응답 속도 개선, 메모리 사용량 감소

# 되도록이면 한글로 쓰삼. 영어 쓴다고 꺼드럭거리지마샘.

# 사용 가이드
# `git config commit.template .gitmessage.txt`: 이 명령어로 설정 ㄱㄱ
# `git commit`: 이 명령어 치면 vim이 열릴거임
# `i` 키 누르고 작성 후 `ESC` -> `:wq`로 나오면 됨
# 수정 안하고 나가려면 `:q!`로 나와짐(수정이 없었으면 `:q`)
